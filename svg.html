01 / LOCAL FORWARD

Deux services distants, une session SSH.

Le PC fixe ouvre la connexion au scanner distant via le port 8080 du client SSH. Les documents numérisés reviennent du scanner vers le poste, dans le sens des particules colorées. Le portable rejoint son port 9100 pour imprimer sur 10.20.0.60:9100. Chaque connexion utilise un channel indépendant dans la même session SSH.

CHEMIN DE LA CONNEXION

Scanner → Serveur SSH → Client SSH → PC fixe
Portable → Client SSH → Serveur SSH → Imprimante

Écoutes : client SSH, ports 8080 et 9100.
Les connexions TCP restent bidirectionnelles ; les particules colorées indiquent le sens des documents.

Appliqués entre les deux extrémités SSH. Les limites portent sur le trafic réseau après compression et chiffrement. Un protocole comme HTTPS peut aussi chiffrer les segments externes.
